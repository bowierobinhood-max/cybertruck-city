# 飞车都市 · Cybertruck City

Browser flying-car game: drive a Tesla Cybertruck through an American-style city.

Play: https://bowierobinhood-max.github.io/cybertruck-city/

Controls: WASD drive, Space/R rise, Shift/F descend, C camera, N day/night, quality 高/中/低.
